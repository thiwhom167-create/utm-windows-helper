นำ ISO เข้า UTM SE บน iPhone

  1. เปิดหน้าของ Microsoft ใน Safari และเลือก ISO ที่ถูกต้อง
  2. ดาวน์โหลดผ่าน Wi-Fi แล้วตรวจไฟล์ในแอป Files → Downloads
  3. เปิด UTM SE แล้วสร้างเครื่องจำลองแบบ Emulate สำหรับสถาปัตยกรรมที่ระบบรองรับ
  4. ในหน้าสื่อบูต เลือก CD/DVD Image แล้วแตะ Browse… เพื่อเลือก ISO
  5. ทำตามหน้าจอ UTM และตัวติดตั้ง หากบูตไม่ขึ้น ให้ตรวจสถาปัตยกรรมและความเข้ากันได้ของ ISO
ข้อจำกัด: UTM SE บน iPhone 11 อาจจำลอง Windows 10/11 ได้ช้ามากหรือบูตไม่สำเร็จ เนื่องจากข้อจำกัดด้าน CPU, RAM และกราฟิก Windows 11 ยังมีข้อกำหนดฮาร์ดแวร์เพิ่มเติม
